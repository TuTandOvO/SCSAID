# scSAID Product Context

- **Register:** Product interface for scientific data exploration.
- **Primary users:** Researchers investigating skin single-cell RNA sequencing datasets.
- **Core purpose:** Browse datasets, search genes, inspect expression and composition, compare conditions, download results, and understand methods.
- **Personality:** Scholarly, restrained, calm, and credible.
- **Design principles:** Preserve scientific clarity and data integrity; keep every workflow available at every viewport size; favor accessible, predictable interaction; retain the established navy, coral, and warm-neutral visual system.
- **Accessibility target:** WCAG 2.2 AA on current Chrome, Edge, Firefox, and Safari 16.4+.
- **Avoid:** Flashy marketing patterns, desktop-only controls, hidden mobile functionality, clipped scientific content, and decorative changes that weaken the existing identity.
